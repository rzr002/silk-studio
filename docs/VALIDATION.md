# 验证记录与能力边界

SILK 0.5.1 是可操作的制袜工坊与专业台原型，尚未证明设计预览与真实衣物一致，也不能向真实机器下发生产程序。

下面的301项模块、77项浏览器检查和性能数字属于2026-10-15的0.5历史快照。0.5.1的公开发布检查单独列出，没有重跑历史原生长测。

## 短时性能观察

以下数字计算的是实际 WebGL 绘制次数除以观察时长，测量时没有连续截图。

| 渲染环境 | 实际编织暖窗口 | 观察帧率 |
| --- | --- | ---: |
| Chromium / ANGLE Metal / Apple M4 | 996 × 930 画布，DPR 1；3.007 秒内绘制 68 次 | 22.61 fps |
| Chromium / ANGLE SwiftShader 软件渲染 | 同尺寸与 DPR；1.303 秒内绘制 7 次 | 5.37 fps |

Metal 检查使用已有 Chromium 的后端启动参数，没有修改应用源码。SwiftShader 冷启动窗口还观察到约 2.23 fps，包含一次约 1.18 秒停顿。软件渲染仍有明显性能限制。

Metal 暂停后的闲置窗口中，绘制计数保持 144 → 144，制作版本也没有变化。动态绘制代码的 30 fps 是上限，不是实际帧率保证。这些短窗口不能代表所有机器、浏览器、复杂设计或长时间运行的性能。

## 历史原生参考案例

专业工作台另有可选 IPC 原生参考求解器。历史验证使用 [ipc-cloth.py](../scripts/ipc-cloth.py) 的固定源码版本：

```text
c74465712d4628cc90fcdf45e5d9814ce58c7a8f04f1fd4469d0730d72b4b4df
```

该次指定完整丝袜案例通过了真实界面的静态步骤和 0 → 55° 动作/保持检查：1 个静态步骤加 80 个动作/保持步骤被接受，另一个不支持的材料请求被拒绝且未改变接受状态。测试代码见 [native-motion.e2e.mjs](../test/native-motion.e2e.mjs)。

55° 接受终态有 1,981 个顶点和 3,920 个三角面。每面 7 个内部/边缘采样点未报告穿入，40 个固定点无漂移，检测到的非共面三角面交叉数为零；实际人体袜尖和额外 0.5 mm 余量的两组 17 点检查均被覆盖。

这仍是 **未标定线性材料、无摩擦的慢速指定案例**：整次浏览器验证约 55.9 分钟，其中动作/保持约 52.7 分钟，对应 1.333 秒模拟时间。它不是实时穿袜过程，也没有验证任意设计或真实材料。有限采样及非共面交叉检查不能证明完整连续表面绝无穿透；原生求解路径与显示帧之间的直线插值也有不同边界。

0.5 没有重跑这次长测。**该历史成功不属于本仓库公开成品样例，也不能用于声称该样例已通过原生运动或实物验证。**

## 0.5.1 公开样例发布检查

新增的 [workshop-portability.test.mjs](../test/workshop-portability.test.mjs) 5 项回归通过；原项目校验 16 项也通过，共 21 项定向检查。这不是一次新的全量模块或浏览器验收，不能替换上面的 0.5 历史数字。

新增检查分别验证：

4. 源尺寸、制作配方与桥接来源不允许用浮点兼容规则隐藏改动。
5. 缺字段、多字段和数组长度变化仍被拒绝。

## 尚未验证

- **真实生产**：没有连接针织机，没有机器原生程序输出，没有打样或工厂验收。
- **材料与光学**：演示材料是合成参数。拉伸曲线、透明度、粗糙度、方向性、纱线尺度外观与真实样品尚未标定。
- **接触与穿着**：浏览器 XPBD 存在上述已知失败；摩擦、完整穿入过程、舒适度和压力预测没有验证。
- **工艺动力学**：齿轮、织针、送缝、染液和蒸汽是事件驱动的运动学展示，不是机器力学、染色化学或热湿定型求解。
- **人体与通用性**：人体尺寸仍是参数化代理，尚无人体测量校准，也没有覆盖任意编辑、动作、极端尺寸和长期运行的可靠性证明。

工坊把这些能力保留为实验状态。完成制作流程、保存成品或通过来源校验，都不会把机器、材料或实物验证状态升级为已验证。
