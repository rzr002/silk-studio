# SILK 0.5.1 技术指南

面向实现与实验复现。本页保留工坊、专业台、材料和数值后端的技术范围；第一次制作请先看[上手指南](GETTING_STARTED.md)。公开验证摘要见[验证说明](VALIDATION.md)。

从一卷纱线开始制作单只长筒丝袜的浏览器原型。主入口是可以操作的三维作坊：穿纱、慢转手轮试织、拉小样、画针目、逐段织袜坯、对齐封尖、染整定型，再试穿和保存。工序之间有前提，做错后需要拆线或拆织返工。

原来的结构、拓扑和物理工具保留在 **[专业台](http://127.0.0.1:4197/lab.html)**。完成的工坊作品可以带制作来源送入专业台，保持同一个设计身份和版本。当前仍是实验软件，未证明预览与实物一致，尚不能输出工业袜机程序。

## 启动

在仓库根目录运行：

```bash
python3 scripts/start.py
```

打开 **http://127.0.0.1:4197**。需要 Python 3 和支持 WebGL 的浏览器；浏览器交互模式无需安装 npm 包、账户或收费 API。Three.js r169 已随项目保存并附 MIT 许可。可选 Newton 对照环境不参与产品运行。

本地 IPC 参考后端使用独立开源 Python 依赖，在项目虚拟环境中安装：

```bash
python3 scripts/setup-reference.py
python3 scripts/start.py
```

启动器优先使用 `.venv-ipc/bin/python`，也可用 `SILK_IPC_PYTHON` 指定现有解释器。`/api/health` 返回真实后端可用状态。参考求解的实际支持范围及整袜验收见下文和[验证说明](VALIDATION.md)；安装成功不代表整件仿真通过。

## 从零做一只丝袜

1. **选纱穿线**：拖动场景里的纱筒到纱筒座，依次穿过导纱眼、张力器和喂纱嘴。手边的按钮提供同样的操作。
2. **试织小样**：绕着手轮拖动，或者用手轮按钮织满试样。抓住小样试拉；调节线圈长度后重新试织，旧样片和拉力记录会保留。确认试样后继续。
3. **编织成形**：设定自然尺寸，在针目草图中逐组画成圈、集圈或浮线，然后启动圆机。袜坯从袜口向袜尖逐段出现，可以暂停。已织针目不能直接改写；先在“拆织与修改”中拆回，再修改重织。
4. **对齐封尖**：拖动两侧袜边或调整错位，送缝封尖。错位接缝会阻止后续整理；拆掉缝线再对齐。未封尖的袜坯保留开放边界。
5. **染整定型**：选色、染整、套板，分别理顺袜口、袜身和足部，再进行加速蒸汽处理。
6. **试穿验货**：套上腿模、查看动作、检查制作流程，给作品起名。导出文件包含制作源、事件、每段针目记录、成品设计及来源桥接；“送到专业台”打开同一件成品。

保存会记录当前浏览器中的制作进度，刷新或打开进度时织机保持暂停。导出 JSON 用于跨浏览器保存；拍照导出当前三维画面 PNG。右键或 Alt 拖动旋转，滚轮缩放，“回到工位”恢复当前工位视角。手机提供相同的工序和工具按钮。

0.5 增加机壳、齿轮与皮带传动、送缝机构、染槽仪表、蒸汽、工作灯、木架收纳及量尺等工具。手轮、线轴、针床和喂纱随制作操作连续运动；送缝、染液和蒸汽随对应工序运行，暂停及短暂动作结束后停止绘制。新增横列只渐显已经提交的袜布，不生成尚未织出的部分。切换工位平滑过渡，右键旋转或滚轮缩放可打断。

画布上的“动态效果”按钮可减少循环动画与过渡；首次使用遵循系统减少动态效果偏好，手动选择单独保存在当前浏览器，不写入作品。活动渲染设有30fps上限，这只是绘制限制，不保证设备达到30fps。当前可见机件是程序化演示结构，动画没有求解真实圆机运动、纱线接触或染整化学。

工坊选择一条**袜口起织、开放袜尖后单独封合的实验路线**，不是所有丝袜的唯一工艺。真实工厂流程依据：[Fogal 制作过程](https://fogal.com/pages/fogals-savoir-faire-luxury-tights)、[FALKE 工艺](https://www.falke.com/si_en/about-us/craftsmanship/)、[Lonati 设备资料](https://www.lonati.com/uploads/2023-1-31/LB41TV-ENG.pdf)。当前先制作单只长筒袜，未加入连裤袜裆部与两腿组装。

真实工艺也决定后续玩法扩展：包覆纱是在弹性芯外缠绕尼龙等长丝的上游工艺，可直接采购纱筒，不必让每个玩家先建制纱厂（[Fulgar 包覆纱](https://www.fulgar.com/en/technology/217/polyamide-66-single-or-double-covered-yarns)）。连裤袜还需依据路线处理裤身、裆部及腰部，不能用一只袜管代替；例如 [Santoni GLC36](https://www.santoni.com/en/products/macchine-ausiliarie/sistemi-di-cucitura-automatici/glc36) 支持拼缝中插入裆片。第一件作品强调穿纱、试样比较、织造、缝合返工、套板检验的操作反馈，再逐步开放不同产品和设备路线。

**制作表现与物理能力分别记录**：48 段、40 组针目是交互展示分组，演示机台的 400 针声明是假设，尚未编译到真实设备。线圈、染色、整理褶皱与蒸汽过程是可追溯的游戏表征；预设自然轮廓、合成样片拉力及针法到刚度的映射不是从真实纱线推导成品的制造仿真。试穿使用贴合初始化，没有模拟完整穿入；真实染色化学、热收缩、纱线接触摩擦、舒适度和压力也未校准。制作检查通过只表示这条实验工序完成，所有实物及制造验证状态仍为 false。

## 专业台

打开 **http://127.0.0.1:4197/lab.html**。从工坊送入的作品保留原始制作记录；专业台继续修改后的版本保留历史来源，不能冒称仍是原工序制造出的成品。独立打开专业台则使用其已有实验作品。

1. 默认进入完整丝袜试穿。点击“组织展开”，用 **区域** 工具点选已有区或拖出新区，再点击“编辑所选组织区”。选择成圈、集圈或浮线，点击针目；返回试穿查看同件作品。实验孔眼和删针会改变派生面片，并在工艺检查中提示风险。
2. 用 **改版** 修改自然轮廓，用 **固定** 添加锚点。**开缝** 沿网格边近似路径，复制两侧边界，保留面片、面积和质量。可拖选两段边界缝合，或点击“缝合最近切口”；拆缝、撤销、改针目和文件恢复都会保留可重放的设计操作。
3. 调整足长、足宽、足跟、腿围、袜长和袜口尺寸。自然尺寸与人台尺寸分别保存。重新贴合是从身体周围初始化，随后求解接触；没有模拟完整穿袜过程。
4. 展开“材料数据”，导入 CSV 或加载合成示例。展开“设备与工艺”，导入设备 JSON 或加载假设设备，检查结构、设备及实样三类状态，导出绑定当前设计版本的技术包。
5. 在试穿和独立材料试验中抓取、释放，或运行位移拉伸试验。后台 Worker 每次推进一个固定 1/60 秒步骤，界面显示已完成的步数、模拟时间和实际求解耗时。质量档改变迭代及子步；慢计算不会假装成实时物理。

上述抓取、材料曲线及独立样片试算适用于浏览器XPBD模式。本地IPC目前使用线性距离弹簧，不支持导入的非线性方向本构、移动抓取目标或无人体网格的独立样片；遇到这些输入会明确拒绝，并保留原接受状态。历史指定参考作品已在真实页面通过指定配置的0→55°数值与接触检查，材料拒绝时也保持状态；这不代表实时交互或材料标定已完成。

右键或 Alt 拖动旋转，滚轮缩放；空格暂停，Ctrl / ⌘ Z 撤销，Shift Z 重做。暂停时可编辑和单步计算。展开图用于结构编辑，坐标图的长度不代表实际尺寸。

“局部材料编辑”中的倍率可应用到当前组织区。保存保存在当前浏览器；导出 JSON 可在其他浏览器继续，PNG 保存当前视图。0.3 统一作品格式为 version 2；早期三个独立实验不自动转换为统一作品。

## 数据接入

材料模板：[`synthetic-material.csv`](../dist/data/synthetic-material.csv)。必需列为 `direction,strain,forceN,widthM,gaugeM`，可带 `cycle,transmittance,areaStretch,split`。方向为 warp/weft/shear，长度单位 m，力 N，应变为比值，透射率 0–1。剪切应变为材料坐标夹角变化的正切 γ。张力由力除以样片宽度得到 N/m。`split=fit/holdout` 区分拟合与留出行。

文件声明的合成来源不能通过界面升级为实测。实测声明、曲线插值拟合、留出验证、力学整件验证和光学验证分别记录；当前没有真实样品数据。周期曲线独立处理，不代表迟滞已经求解。范围以外的外推和光学查表超范围会保留标记。

设备模板：[`hypothetical-machine.json`](../dist/data/hypothetical-machine.json)。包含来源、机型类别、针位、喂纱路、每横列颜色数、动作、浮线、移圈及组织边界规则。这份模板是软件假设，未冒用真实厂商参数。

技术包包含同版本设计源、全部组织区、尺寸、材料、几何、设计操作、规则报告及后处理声明。导入的样品记录保留编号、版本和声明状态；即使记录写着“通过”，仍标记 `evidenceVerified: false`，不会升级为实样已验证。设备能力匹配也只基于来源声明。当前 `productionVerified: false`、`nativeProgram: null`；没有可信外部验证器或工业机器编译器。

## 物理及外观范围

- CPU XPBD：重力、阻尼、方向拉伸、剪切、距离式弯曲、抓取反力估计与有限厚度接触。导入的方向曲线进入力及切线；未测方向继续使用实验线性约束。
- 完整单腿丝袜：闭合脚尖、足部、足跟、踝、小腿、大腿和弹性袜口。显示人体与接触人体使用同一几何来源。
- 浏览器XPBD自接触使用非邻接顶点与三角形及空间哈希；连续检测覆盖运动顶点与静止三角形。**不具备完整运动三角形或边对边 CCD**，不保证所有快速运动和极端折叠均无穿透。原生IPC的逐段路径检查范围另行记录。
- 光学由局部横纵伸长、剪切及面积变化驱动覆盖率、透射率和粗糙度，可接透光数据表。孔隙模型与粗糙度仍含假设，尚非标定后纱线级光学。
- 可见纱线来自组织图，再随织物表面变形；尚未求解真实线圈间接触、摩擦、滑移和脱散。组织到等效刚度的映射尚未实测。

封口使用自由同心环网格，方向不明确的封口面按面积变化计算各向同性实验外观。封口盘的 UV 不唯一，当前可抓取、固定；该盘的精确开缝和局部改版尚未接入，不能用袜身 UV 路径代替。数值伸长上限与路径拦截用于稳定计算，不代表材料强度；触发或残余冲突会在界面提示。

反力为最终子步约束反力估计，未包含接触与数值硬限制反力，单位 N；不等于测力计或穿着压力。本软件尚未证明预览与实物一致，也未生成可直接运行的工业机器程序。

浏览器交互内核仍有两项整袜强测试失败，存在封尖覆盖和运动接触反例。新增本地IPC路线采用原生barrier、CCD、稀疏Newton与线搜索；历史指定完整参考作品的0→55°真实UI流程通过，81个接受步骤均收敛、推进完整dt并到达完整请求姿态，终态人体交叉为零、27440面内/边缘采样无穿入、脚尖两组探针各17/17覆盖、40个固定点零漂移。失败保留原作品和人体姿态，过期结果不写入当前设计。

该次原生运动含一次末态保持，共1.333秒模拟时间，实际等待约52.7分钟；80个动作/保持步骤耗时中位数约33秒。它是慢速数值参考，当前快速浏览器模式和原生参考模式都不能作为实物一致性或生产依据。该验收针对指定配置，不自动覆盖新工坊生成的不同尺寸或针目作品。公开配置与失败摘要见[验证说明](VALIDATION.md)。

IPC参考模式按逐段求解路径做连续检查，并单独记录前后状态直线插值是否安全。这两个结果不能混用；工作台提交接受后的离散状态，不对未验证的直线插值生成动画。数值收敛精度和材料测量精度分别记录。

## 验证与复现

以下为开发命令，需要 Node.js 20 或更高版本；npm 用于安装开发依赖和调用脚本。运行工坊本身不依赖 Node.js。浏览器检查使用 Playwright 与 Chromium，先安装：

```bash
npm ci
npx playwright install chromium
```

原生参考另需上文的 Python 依赖，其长测可能耗时接近一小时，应独立运行。

```bash
npm test
npm run test:browser
npm run test:workshop-view
npm run test:workshop-motion
npm run test:workshop-scene
npm run test:workshop-navigation
npm run test:workshop-portability
npm run test:lab
npm run test:view
npm run test:worker
```

浏览器脚本需要 Playwright 与 Chromium，仅用于开发验证。`PLAYWRIGHT_PATH` 可指定已安装的 Playwright 路径；依赖发现方式以测试脚本为准。`WORKSHOP_URL` 指定工坊地址；旧专业台测试会将 `DEMO_URL` 的同源地址转到 `/lab.html`，也可以显式设置 `LAB_URL`。运行 demo 不依赖测试工具。实际结果与尚未通过的物理门禁见[验证说明](VALIDATION.md)。测试运行会将本地证据写入 `evidence/`；完整原始文件不作为本页链接目标。

2026-10-15 的0.5记录中，实际制作/动态/手机/显示/导航共77项通过；全量模块301项中299通过，保留2个既有XPBD封尖/运动失败。本机M4 Metal在实际编织的3秒暖窗口约22.6fps，默认SwiftShader软件渲染约5.4fps；两者是当时短测，不是通用性能承诺。公开范围与复现方式见[验证说明](VALIDATION.md)。

0.5.1在只含公开文件的干净副本中重新验证314项模块（312通过、2个既有失败）、HTTP合同7项及跨运行时文件/专业台路线4项，详见[发布检查](VALIDATION.md#051-公开发布检查2026-10-16)。

导航与染整动态检查默认使用仓库中的 `examples/finished-stocking.json`，也可通过 `WORKSHOP_FIXTURE` 或 `WORKSHOP_MOTION_FIXTURE` 指定主流程现场导出的成品文件。完整从零制作仍由 `npm run test:browser` 验证；样例和隔离渲染不作为玩家完成制作的证据。

另外曾实际执行 Newton CPU 样片对照，范围限于该样片及当时参数。其预编译依赖尚未满足全链路纯开源准入，因此没有接入产品；不能把该对照视为工坊能力。公开后端状态以[验证说明](VALIDATION.md)为准。
