# 做第一只丝袜

SILK 0.5.1 在浏览器里制作单只虚拟长筒丝袜。先完成一条基础路线，再试着改变小样、针目和尺寸。当前纱线响应为合成演示，制作检查通过只表示工序完成。

## 打开工坊

需要 Python 3 和支持 WebGL 的浏览器。在仓库根目录运行：

```bash
python3 scripts/start.py
```

打开 [http://127.0.0.1:4197](http://127.0.0.1:4197)。运行工坊使用已打包的资源；Node.js、Playwright 和可选 IPC 依赖用于开发或专业数值实验。不要直接双击 `index.html`。

如果端口已占用，可运行 `python3 scripts/start.py --port 4200`，然后打开 `http://127.0.0.1:4200`。结束时在启动服务的终端按 Ctrl+C。

## 认识手边的工具

中间是可以操作的三维作坊，右边工具柜提供对应动作。左边工序按钮可以提前看其他工位，完成前提后才能实际加工。下方“下一步”会说明当前该做什么。

| 操作 | 用途 |
|---|---|
| 拖动纱筒、手轮、小样或袜边 | 上机、试织、试拉、对齐 |
| 点击场景中的导纱器与踏板 | 穿线与送缝 |
| 右键或 Alt 拖动 | 旋转视角 |
| 滚轮 | 缩放 |
| 回到工位 | 恢复当前工位视角 |
| 动态效果 | 减少或恢复连续动画与视角过渡 |
| 拍照 | 导出当前画面的 PNG |

手机可以触摸场景和使用工具按钮。针目细节编辑建议留出较大的画面空间。

## 1. 选纱，把线送到针床

从纱架选择一卷纱，拖到纱筒座；也可以点击“把纱筒放上机器”。依次点击 **导纱眼、张力器、喂纱嘴**，或使用工具柜中的三个穿线按钮。

每穿过一处，纱路会延长一段。顺序错了会提示；完成三处后才能试织。需要重来时，使用“退回纱线，重新穿”。

## 2. 织一块小样，试拉再决定

围着场景里的手轮拖动，观察小样增长。也可以点击两次“转动手轮，试织一段”，把计数织到 **8/8**。

向右拖动小样，或保留默认 35% 标线后点击“拉到标线，看看回弹”。试拉过完整小样后，才能点击“用这次试样继续制作”。

想做比较，先试拉一块，再改变线圈长度，重新织满和试拉。旧小样会保留在桌上。超过演示伸长范围的样片会被标记受损；调整线圈长度后另织一块。显示的拉力尚未实测，不能作为真实纱线性能依据。

## 3. 改尺寸和针目，再开机

先设置袜长、小腿围与足长。第一件可保留默认尺寸。

打开“展开编辑”，选择成圈、集圈或浮线，拖动绘制尚未织出的区域。第一件建议以成圈为主；整段只画浮线会在最后的制作检查中报错。

点击“启动圆机”，袜坯会从袜口向袜尖逐段出现。可以用“暂停检查”停下，再编辑尚未织出的针目。织到 **48/48** 后得到袜尖开放的袜坯。

想修改已经织出的部分，先暂停并展开“拆织与修改”，输入更早的段数，点击“拆回纱线”，再编辑和重新编织。拆回会让之后的封尖、染整和试穿失效，这些工序需要重做。48 段是展示分组，不是已经验证的真实袜机程序。

## 4. 对齐袜尖，送缝封合

把两侧袜边拖到同一条参考线上，或把“边缘错位”调到 0。点击场景踏板或“踩下踏板，送缝一段”，等待封尖完成。

如果故意错位后缝合，后面的染整会被挡住。点击“拆掉这条缝线，重新对齐”，调正后再送缝。拆线也会清除后续整理结果。

## 5. 染整、套板和定型

选择目标色样，再点击“放入染槽，处理一段”，等待完成。随后：

1. 点击“把丝袜套上定型板”。
2. 分别拉平袜口、理顺袜身、对齐足部。
3. 点击“启动蒸汽定型”，等待处理结束。

三处没有整理完时，定型按钮不可用。换色会要求重新染整；加工时间已加速，染液与蒸汽是工序表现，尚未求解真实化学或热收缩。

## 6. 看看成品，带走作品

点击“套上腿模，整理位置”，调节动作预览，再点击“查看制作结果”。可以给作品起名。

这里展示的是贴合初始化后的形状，没有模拟完整穿入。制作检查不会把材料、物理或机器验证升级为已通过。

| 保存方式 | 保存内容 |
|---|---|
| 保存 | 当前浏览器里的制作进度；重新打开时织机暂停 |
| 导出进度 | 便携 JSON，包括制作源与事件；成品还包含设计和来源桥接 |
| 打开 | 载入导出的项目；文件会接受结构和事件一致性检查 |
| 拍照 | 当前三维视图 PNG |

浏览器保存可能被浏览器清理。重要作品请导出 JSON。“另做一只”会新建当前作品，建议先导出已有作品。

## 继续到专业台

成品的“送到专业台进一步检查”会打开 [/lab.html](http://127.0.0.1:4197/lab.html)，保留同一个作品身份、版本和制作来源。专业台可以检查组织、自然轮廓、开缝、材料数据及设备规则。

直接从导航进入专业台会打开它自己的实验作品；要继续当前成品，请使用成品工位的按钮。专业台继续修改后，历史制作来源会保留，但不能把修改后的版本当作原工序已经制作出的结果。

## 遇到问题

- **按钮不能用**：看“下一步”和提示。常见前提是未按顺序穿纱、小样未织满或未试拉、袜尖错位、套板后缺少一处理顺。
- **画面空白**：确认通过本地 HTTP 地址打开，浏览器启用 WebGL。尝试当前版本的桌面浏览器，并附浏览器与图形后端信息报告问题。
- **动作卡顿**：减少动态效果。软件渲染可能较慢；30fps 是上限而非性能保证。
- **导入被拒绝**：保留原导出文件。不要单独修改 JSON 中的配方字段，事件记录和派生设计需要一致。
- **想生成真实机器文件**：当前尚无工业机器编译器，技术包中的 `nativeProgram` 为 `null`。

更多实现和限制见[技术指南](TECHNICAL_GUIDE.md)，验证记录见[验证说明](VALIDATION.md)。
