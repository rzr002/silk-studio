# SILK · 丝物

**在浏览器里，从一卷纱做起。**

SILK 是开源 3D 制袜工坊原型。把纱筒装上机器，亲手穿纱、试织、画针目、编织、封尖、染整，最后在腿模上查看自己的第一只长筒丝袜。织错了，可以拆回重织；袜尖缝歪了，需要拆线再对齐。

[做第一只丝袜](#做第一只丝袜) · [English](README.en.md) · [上手指南](docs/GETTING_STARTED.md)

> **0.5.1 实验原型**：目前制作的是虚拟作品。纱线响应与设备参数尚未实样校准，实物一致性和真实机器生产均未验证。

![SILK 三维制袜工坊，包含可操作机台、纱架与工位工具柜](docs/images/workshop.png)

## 做第一只丝袜

需要 Python 3 和支持 WebGL 的浏览器。桌面浏览器适合细致编辑；手机也有触控与工具按钮。

```bash
git clone https://github.com/rzr002/silk-studio.git
cd silk-studio
python3 scripts/start.py
```

打开 **[http://127.0.0.1:4197](http://127.0.0.1:4197)**，从选纱台开始。工坊运行使用仓库内的资源，不需要 npm 安装或付费 API。当前界面为中文。

## 让每一步留下变化

| 亲手操作 | 作坊里的结果 |
|---|---|
| 拖纱筒上机，依次穿过导纱眼、张力器和喂纱嘴 | 纱路逐段连接，穿好后才能试织 |
| 转手轮织小样，试拉，再调线圈长度 | 留下不同设置的小样和演示拉力记录，选一次试样继续 |
| 改袜长、腿围和足长，拖动画成圈、集圈或浮线 | 袜坯从袜口向袜尖逐段出现；已织部分要先拆回才能改 |
| 对齐两侧袜边，踩踏板封尖 | 错位接缝会挡住后续工序，拆线后可以重来 |
| 染色、套板，理顺袜口、袜身和足部，再定型 | 整理同一件作品，送到腿模上检查、命名和保存 |

![SILK 编织工位中的圆机、纱路与袜坯](docs/images/knitting.png)

机台传动、针床、送缝、染液和蒸汽随操作运动。切换工位有连续视角过渡，静止后停止绘制。用“动态效果”可减少动画，首次打开遵循系统偏好。

“保存”记录当前浏览器进度；导出 JSON 可以带走作品和制作记录，拍照保存当前三维画面。重新打开进度时织机保持暂停。完整操作见[上手指南](docs/GETTING_STARTED.md)。

## 想研究结构，可以继续进专业台

成品的“送到专业台”会带上同一个设计 ID、版本和制作来源。这里可以改自然轮廓、编辑组织区、开缝与缝合、导入材料数据、检查假设设备规则。也可直接打开 **[/lab.html](http://127.0.0.1:4197/lab.html)**。

![SILK 专业台中的丝袜结构与物理实验工具](docs/images/lab.png)

专业台保留了浏览器 XPBD 和可选本地 IPC 数值参考。实现、材料格式与后端限制见[技术指南](docs/TECHNICAL_GUIDE.md)。

## 开始前的几个问题

**没有服装经验也能玩？** 先跟着当前工位的“下一步”操作。拖动和点击场景物件，或用工具柜里的对应按钮。第一件可以保留默认尺寸和成圈组织。

**能做出真实丝袜吗？** 当前导出数字作品和实验技术包。48 个展示段与假设针位用于交互分组；技术包的 `nativeProgram` 仍是 `null`。真实纱线量测、设备编译和实样验收还需要继续完成。

**已经接入 AI 设计了吗？** 当前使用直接操作和参数编辑，没有集成 AI 模型或云 AI 服务。

**仿真有多可靠？** 0.5.1 在干净副本中通过了 312/314 项模块测试，保留 2 项 XPBD 整袜失败；文件打开、修改拒绝和专业台交接的 4 项浏览器检查通过。此前 0.5 的完整制作与显示有 77 项检查通过。指定 IPC 参考案例推进 1.333 秒模拟花了约 52.7 分钟，仍不代表任意作品或实物一致。范围与复现记录见[验证说明](docs/VALIDATION.md)。

**为什么画面可能慢？** WebGL 性能取决于设备和图形后端，软件渲染尤其慢。可减少动态效果；物理专业台的慢速参考求解与工坊动画分别运行。

## 一起把工坊做下去

欢迎提交可复现的问题、交互改进和代码贡献。当前需要实际纱线与样片数据、独立接触回归、设备规则，以及让新手更容易看懂的制作反馈。提出物理或生产能力时，请同时带上输入、验证方法和失败样例。

开发验证使用 Node.js；浏览器检查另需 Playwright 和 Chromium。命令与模块说明在[技术指南](docs/TECHNICAL_GUIDE.md)。
